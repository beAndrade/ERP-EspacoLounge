# Documentation Maintenance

## Purpose

Documentation must evolve together with the software.

Every completed feature should trigger a documentation review.

---

## Workflow

New Feature

↓

Implementation

↓

Testing

↓

Documentation Review

↓

Documentation Update

↓

Commit

---

## Responsibilities

Update:

- Product.md
- Architecture.md
- Database.md
- Modules.md
- Brand.md
- Roadmap.md
- Changelog.md

when appropriate.

---

## ADR

Whenever an important architectural decision is made,

suggest creating a new ADR.

---

## Project State
