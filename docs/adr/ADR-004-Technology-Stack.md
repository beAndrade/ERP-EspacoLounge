# ADR-004 — Technology Stack

Status

Accepted

Date

2026-08-05

---

## Context

The platform requires technologies capable of supporting long-term growth.

Developer productivity is also a priority.

---

## Decision

Frontend

Angular

Backend

Node.js

Database

PostgreSQL

AI Assistant

Cursor

Version Control

Git + GitHub

Containerization

Docker

---

## Alternatives

Evaluate technologies only when there is a measurable benefit.

Avoid unnecessary migrations.

---

## Consequences

Positive

Stable ecosystem.

Strong community.

Scalable architecture.

Developer productivity.

---

## Future

Review technology choices only when justified by business needs.
