# Architecture Decision Records (ADR)

## Purpose

This directory stores Architecture Decision Records for the Nexa Platform.

An **ADR** documents:

- Context
- Problem
- Alternatives
- Decision
- Consequences

ADRs preserve *why* a decision was made. System architecture *description* lives in [../02-architecture/](../02-architecture/README.md).
