# Architecture Decision Records (ADR)

## Purpose

This directory stores the most important architectural and strategic decisions made during the development of the Nexa Platform.

Every ADR documents:

- Context
- Problem
- Alternatives
- Decision
- Consequences

The purpose is to preserve the reasoning behind important decisions so future contributors understand why they were made.
