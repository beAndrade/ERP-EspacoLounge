# Product Demo Playbook

**Status:** Living Document

---

# Purpose

Standardize Nexa product demonstrations.

Demonstrations should focus on solving customer problems rather than showcasing every feature.

---

# Demo Structure

Business Problem

↓

Current Workflow

↓

Nexa Workflow

↓

Business Benefit

---

# Rules

Never start with the Dashboard.

Start with the customer's biggest pain.

Examples:

Scheduling

↓

Show Agenda

Commissions

↓

Show Payroll

Customer History

↓

Show Customer Profile

Avoid feature tours.

---

# End of Demo

Confirm:

Did the demonstration solve the customer's main problem?

Define the next step.
