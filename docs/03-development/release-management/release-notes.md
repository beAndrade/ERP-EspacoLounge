# Release Notes

This document records user-facing improvements delivered by the Nexa platform.

Release Notes communicate new functionality, enhancements and important changes for each released version.

Unlike the Changelog, Release Notes focus on product value rather than technical implementation.

---

# Release Format

Every release should include:

- Version
- Release Date
- Release Type
- Highlights
- New Features
- Improvements
- Bug Fixes
- Breaking Changes (if any)
- Known Issues
- Next Milestone

---

# Release Types

## Major Release

Large product evolution introducing significant functionality.

Example:

- New Product EPIC
- Major architectural capability
- New platform module

---

## Minor Release

New functionality without breaking compatibility.

Example:

- New screens
- Workflow improvements
- Additional reports

---

## Patch Release

Bug fixes and small improvements.

Example:

- Fixes
- UI adjustments
- Performance improvements
