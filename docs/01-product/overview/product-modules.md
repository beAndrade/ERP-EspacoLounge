# Modules

## Philosophy

Nexa is composed of independent business modules built on top of a shared Core Platform.

Every module inherits the same infrastructure while implementing its own business rules.

## Architecture Principle

Business-specific logic belongs inside the corresponding module.

Shared logic belongs to the Core Platform.
