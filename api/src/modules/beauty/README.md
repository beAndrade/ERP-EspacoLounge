# Beauty Module

## Purpose

Contains all business rules specific to the Beauty vertical.

## Contains

Examples include:

- Appointments
- Customers
- Professionals
- Products
- Inventory
- Financial operations
- Commissions

## Must NOT contain

- Authentication
- Billing platform
- Generic utilities
- Infrastructure adapters

## Dependencies

Beauty may depend on:

- Core
- Shared
- Platform
- Features
- Infrastructure
